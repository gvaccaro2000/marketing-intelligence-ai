# Creative Testing Process

## Naming

`CHANNEL-CAMPAIGN-NN`, e.g. `META-AEO-01`, `GGL-UAC-02`, `APL-CPI-03`. Three live creatives per
campaign.

## What we can measure per creative

`ua_spend` carries `creative_id`, so CPI, CTR and IPM can be read per creative.

## Test cycle

1. New variant goes live next to the incumbent.
2. Run for **5 days**.
3. Read CPI first, then CTR.
4. Winner stays; loser is paused.

## Fatigue

Refresh when CTR drops ≥ 20%.
